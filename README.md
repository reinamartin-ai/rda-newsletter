# rda-newsletter

Imágenes y plantilla HTML del reporte mensual "IA en ingeniería estructural" que reciben por mail
el equipo de IA de RDA Ingeniería. Las imágenes se sirven con GitHub Pages:

- `img/logo-rda.png` — logo RDA (440 px, se muestra a 190 px)
- `img/banner-01..30.jpg` — portadas (1200×480), fotos de obras de rdaingenieria.com; rotan por mes
  (NN = ((año×12 + mes) mod 30) + 1, con dos dígitos)
- `plantilla.html` — estructura del mail (tablas e estilos en línea, 600 px)
